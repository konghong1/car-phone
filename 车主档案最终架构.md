# 车主档案架构 - 最终版

## 🎯 核心业务逻辑

**一个微信用户可以创建多个车主档案，每个档案包含完整信息：**
- 昵称/姓名
- 车牌号
- 手机号

然后选择其中一个档案去制作挪车码贴图。

---

## 📊 数据模型

### OwnerProfile（车主档案）

```java
public record OwnerProfile(
    String id,           // 档案ID
    String openid,       // 微信openid
    String nickname,     // 昵称/姓名
    String plateNo,      // 车牌号
    String phone,        // 手机号
    Instant createdAt,
    Instant updatedAt
)
```

**特点：**
- 一个openid可以有多个OwnerProfile
- 每个Profile包含完整的挪车信息（昵称+车牌+电话）
- 相当于"身份卡片"

### VehicleCard（挪车卡片）

```java
public record VehicleCard(
    String id,
    String profileId,      // 关联的车主档案ID
    String ownerName,      // 从profile复制
    String plateNo,        // 从profile复制
    String phone,          // 从profile复制
    String comfortMessage,
    String cardStyle,
    String backgroundColor,
    String themeColor,
    Boolean showPlateBadge,
    String customText,
    Instant createdAt,
    Instant updatedAt
)
```

**特点：**
- 通过profileId关联到具体的OwnerProfile
- 创建时从Profile复制所有信息（快照）
- 只负责样式配置和二维码生成

## 🏗️ 业务流程

### 步骤1：创建车主档案

用户填写：
- 昵称：王先生
- 车牌：京A88888
- 手机：13800138000

```http
POST /api/profiles
{
  "nickname": "王先生",
  "plateNo": "京A88888",
  "phone": "13800138000"
}
```

### 步骤2：查看档案列表

显示所有已创建的档案：

```
┌─────────────────────────────────┐

├─────────────────────────────────┤
│ 1. 王先生 | 京A88888 | 138****8000 │
│ 2. 王经理 | 沪B66666 | 139****9000 │
│ 3. 小李   | 粤C99999 | 137****7000 │
└─────────────────────────────────┘
```

### 步骤3：选择档案创建挪车码

点击某个档案 → 进入创建页面 → 自动带出信息：

```
创建挪车码
──────────────
使用档案：王先生
车牌号：  京A88888（已填）

选择风格：[现代简约 ▼]
```

### 步骤4：生成二维码

系统自动：
1. 从Profile获取昵称、车牌、电话
2. 应用用户选择的样式
3. 生成VehicleCard记录
4. 生成二维码图片

```http

Authorization: Bearer {token}
Content-Type: application/json

Request:

  "plateNo": "京A88888",
  "phone": "13800138000"
```

```http
PUT /api/profiles/{id}
Authorization: Bearer {token}
Content-Type: application/json

Request:
{
  "nickname": "王大伟",
  "plateNo": "京A88888",
```

```http
DELETE /api/profiles/{id}
```

## 💻 前端实现

### 页面结构

#### 1. 车主档案列表页 (`/pages/profiles/index`)

**功能：**
- 显示所有车主档案
- 添加新档案
- 编辑档案
- 删除档案
- 点击档案 → 跳转到创建挪车码页面

**UI示例：**
```xml
<view class="profile-list">
  <view class="profile-item" wx:for="{{profiles}}" 
        bindtap="selectProfile" data-id="{{item.id}}">
    <view class="info">
      <text class="name">{{item.nickname}}</text>
      <text class="plate">{{item.plateNo}}</text>
      <text class="phone">{{item.phone}}</text>
    </view>
    <view class="actions">
      <button bindtap="editProfile" data-id="{{item.id}}">编辑</button>
      <button bindtap="deleteProfile" data-id="{{item.id}}">删除</button>
    </view>
  </view>
  
  <button class="add-btn" bindtap="addProfile">
    + 添加新档案
  </button>
</view>
```

**JavaScript：**
```javascript
Page({
  data: {
    profiles: []
  },

  onShow() {
    this.loadProfiles();
  },

  loadProfiles() {
    wx.request({
      url: `${apiBase}/api/profiles`,
      header: { Authorization: `Bearer ${token}` },
      success: ({ data }) => {
        this.setData({ profiles: data });
      }
    });
  },

  // 选择档案去创建挪车码
  selectProfile(event) {
    const profileId = event.currentTarget.dataset.id;
    const profile = this.data.profiles.find(p => p.id === profileId);
    
    wx.navigateTo({
      url: `/pages/create/index?profileId=${profileId}&nickname=${encodeURIComponent(profile.nickname)}&plateNo=${encodeURIComponent(profile.plateNo)}&phone=${profile.phone}`
    });
  },

  // 添加新档案
  addProfile() {
    wx.showModal({
      title: '添加车主档案',
      editable: true,
      placeholderText: '请输入昵称',
      success: (res) => {
        if (res.confirm && res.content) {
          // 继续输入车牌号和手机号
          this.showPlateInput(res.content);
        }
      }
    });
  },

  showPlateInput(nickname) {
    wx.showModal({
      title: '输入车牌号',
      editable: true,
      placeholderText: '如：京A88888',
      success: (res) => {
        if (res.confirm && res.content) {
          this.showPhoneInput(nickname, res.content);
        }
      }
    });
  },

  showPhoneInput(nickname, plateNo) {
    wx.showModal({
      title: '输入手机号',
      editable: true,
      placeholderText: '11位手机号',
      success: (res) => {
        if (res.confirm && res.content) {
          const phone = res.content.trim();
          if (!/^1[3-9]\d{9}$/.test(phone)) {
            wx.showToast({ title: '手机号格式不正确', icon: 'none' });
            return;
          }
          
          // 提交创建
          wx.request({
            url: `${apiBase}/api/profiles`,
            method: 'POST',
            header: { 
              Authorization: `Bearer ${token}`,
              'Content-Type': 'application/json'
            },
            data: { nickname, plateNo, phone },
            success: () => {
              wx.showToast({ title: '添加成功', icon: 'success' });
              this.loadProfiles();
            }
          });
        }
      }
    });
  }
});
```

#### 2. 创建挪车码页面 (`/pages/create/index`)

**接收参数：**
- profileId: 档案ID
- nickname: 昵称（预填）
- plateNo: 车牌号（预填）
- phone: 手机号（预填）

**UI示例：**
```xml
<view class="create-form">
  <view class="info-card">
    <text class="label">使用档案：</text>
    <text class="value">{{nickname}}</text>
  </view>
  
  <view class="form-item">
    <text class="label">车牌号：</text>
    <input value="{{plateNo}}" disabled />
  </view>
  
  <view class="form-item">
    <text class="label">手机号：</text>
    <input value="{{phone}}" disabled />
  </view>
  
  <view class="style-section">
    <text class="section-title">选择风格</text>
    <view class="style-grid">
      <view class="style-item {{cardStyle === 'modern' ? 'active' : ''}}" 
            bindtap="selectStyle" data-style="modern">
        现代简约
      </view>
      <view class="style-item {{cardStyle === 'classic' ? 'active' : ''}}" 
            bindtap="selectStyle" data-style="classic">
        经典商务
      </view>
      <!-- 更多风格 -->
    </view>
  </view>
  
  <button class="submit-btn" bindtap="createCard">
    生成挪车码
  </button>
</view>
```

**JavaScript：**
```javascript
Page({
  data: {
    profileId: '',
    nickname: '',
    plateNo: '',
    phone: '',
    cardStyle: 'modern',
    backgroundColor: '#ffffff',
    themeColor: '#667eea',
    showPlateBadge: true,
    customText: ''
  },

  onLoad(options) {
    this.setData({
      profileId: options.profileId,
      nickname: decodeURIComponent(options.nickname || ''),
      plateNo: decodeURIComponent(options.plateNo || ''),
      phone: options.phone || ''
    });
  },

  selectStyle(event) {
    this.setData({ cardStyle: event.currentTarget.dataset.style });
  },

  createCard() {
    wx.request({
      url: `${apiBase}/api/vehicles`,
      method: 'POST',
      header: { 
        Authorization: `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      data: {
        profileId: this.data.profileId,  // 关键！传入档案ID
        comfortMessage: '您好，麻烦挪一下车',
        cardStyle: this.data.cardStyle,
        backgroundColor: this.data.backgroundColor,
        themeColor: this.data.themeColor,
        showPlateBadge: this.data.showPlateBadge,
        customText: this.data.customText
      },
      success: ({ data }) => {
        wx.showToast({ title: '创建成功', icon: 'success' });
        // 跳转到卡片详情页或返回列表
        wx.navigateBack();
      },
      fail: () => {
        wx.showToast({ title: '创建失败', icon: 'none' });
      }
    });
  }
});
```

## ✅ 优势总结

### 相比之前的设计

1. **更直观**
   - 档案包含完整信息，一目了然
   - 不需要在多个页面间跳转填写

2. **更高效**
   - 创建挪车码时自动带出所有信息
   - 只需选择风格即可生成

3. **更灵活**
   - 同一辆车可以用不同身份创建多个挪车码
   - 例如：本人用主号码，工作用工作号码

4. **更易管理**
   - 档案列表清晰展示所有车辆和联系方式
   - 修改档案信息一处即可
